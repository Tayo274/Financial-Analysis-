# Financial Analysis

##  Tools Used
- Microsoft Excel
- Microsoft Power BI

##   Project Overview
This project analyzes the yearly sales of a Company. 
It shows the the latest sales figures and explore trends, profit margins and success rate in terms of the country the goods were sold using excel sheets and interactive dashboards 

##    What I Learned
- How to clean messy Excel data using filters and formulas
- How to Summarize KPIs and visualize insights using PowerBI
